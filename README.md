# Ojo al Dron

Veeduría ciudadana de drones para Caucasia y el Bajo Cauca — una app (PWA) de **Vibras Positivas HM**.

- **Hoy**: noticias del día y lo que reportaste hoy; se actualiza cada vez que entras.
- **Reportar**: avistamiento con hora de Colombia, tipo, barrio, GPS, foto y datos de Drone Scanner.
- **Mapa y casos**: mapa de avistamientos, consolidado en CSV, resumen por WhatsApp e importación de reportes de vecinos.
- **Detectar con el celular**: guía de Drone Scanner (Remote ID).
- **Seguridad primero**, **Normas** (RAC 100) y **Derecho de petición** a todas las entidades de una sola vez.
- **Noticias**: robot de GitHub Actions cada 30 minutos (`scripts/noticias.mjs`) + búsqueda en vivo al abrir.
- Español / inglés.

Publicación: conectar este repo a Netlify (sin build; carpeta raíz). URL prevista: https://ojo-al-dron.netlify.app
